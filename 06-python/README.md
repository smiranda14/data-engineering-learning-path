# Python for Data Engineering

This section documents Python foundations for data processing, automation, and integration with databases and data services.

## Topics

- Variables, data types, conditions, loops, and functions.
- Lists, dictionaries, sets, and comprehensions.
- Reading and writing CSV, JSON, and text files.
- Working with pandas and tabular data.
- Exceptions, logging, and debugging.
- Connecting Python to relational databases.
- Writing reusable scripts and basic tests.
- Working with APIs (introductory).

## Practice Ideas

- Read a CSV product catalog and profile its columns.
- Find missing values and duplicate product IDs.
- Standardize text fields and export a cleaned CSV.
- Connect to PostgreSQL and load a small dataset.
- Build a script that logs validation errors.
