# Data Engineering Learning Path 🚀

A hands-on portfolio documenting my transition from Data Analytics to Data Engineering through SQL, database design, data quality, Python, cloud technologies, and practical projects.

I am a Data Analyst expanding my technical skills and applying my analytical and business background to build reliable, well-structured data solutions. This repository brings together learning notes, exercises, useful resources, and projects that demonstrate my progress.

## 🎯 Learning Objectives

- Strengthen SQL and relational database skills.
- Understand database design, data modeling, and partitioning.
- Practice data validation, cleaning, and transformation.
- Learn ETL / ELT concepts and data pipeline fundamentals.
- Develop Python skills for data processing and automation.
- Explore cloud data services, especially AWS.
- Build portfolio projects using realistic, public, or synthetic datasets.
