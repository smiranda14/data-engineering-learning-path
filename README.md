# Data Engineering Learning Path 🚀

Welcome to my learning journey!

I am a Data Analyst expanding my technical skills and transitioning towards Data Engineering. This repository documents my progress through hands-on SQL exercises, technical notes, and practical projects.

My goal is to combine analytical thinking and business understanding with the technical foundations required to build reliable data systems.

## 🎯 Learning Objectives

- Strengthen SQL and database management skills.
- Understand relational database design and data modeling.
- Practice data cleaning, validation, and transformation.
- Learn ETL and ELT concepts and workflows.
- Develop Python skills for data processing and automation.
- Explore cloud data services, especially AWS.
- Build and document practical data engineering projects.

## 📚 Learning Roadmap

| Area | Topics | Status |
|---|---|---|
| SQL Fundamentals | SELECT, filtering, joins, aggregation, subqueries | Completed coursework; continued practice |
| Advanced SQL | CTEs, views, window functions, set operations | In progress |
| Database Design | Constraints, normalization, partitioning | In progress |
| Data Quality | Validation rules, duplicates, missing values | Planned |
| Data Transformation | ETL / ELT concepts and transformations | Planned |
| Python | Data manipulation and automation | Planned |
| Cloud Data Engineering | AWS S3, Athena, Glue | Planned |
| Data Pipelines | Pipeline design and orchestration | Planned |
