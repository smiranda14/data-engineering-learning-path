# SQL Fundamentals

This section builds the foundations for querying relational databases. The goal is to understand how to retrieve, filter, combine, and summarize data accurately.

## Topics

1. **Query basics:** SELECT, DISTINCT, aliases, LIMIT.
2. **Filtering:** WHERE, AND, OR, NOT, IN, BETWEEN, LIKE, IS NULL.
3. **Sorting:** ORDER BY and NULL ordering.
4. **Aggregations:** COUNT, SUM, AVG, MIN, MAX.
5. **Grouping:** GROUP BY and HAVING.
6. **Joins:** INNER, LEFT, RIGHT, and FULL OUTER JOIN.
7. **Subqueries:** scalar and multi-row subqueries.
8. **Data changes:** introductory INSERT, UPDATE, and DELETE concepts.

## Practice Plan

- Write queries against small sample tables.
- Predict the result before running each query.
- Practice joins using related tables such as customers, orders, and products.
- Save each exercise as a separate `.sql` file.
